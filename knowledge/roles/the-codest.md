# The Codest — Software Engineer

## Role

Nicolas was a Software Engineer at The Codest from July 2021 to October 2022, working remotely from Warsaw. He worked on two client projects: Epassi, a benefits management platform, and a nursery management system.

## Epassi

- Worked within a 15+ year old legacy codebase, extending a role-based permission system with a flexible UI and refactoring toward full test coverage.
- Reviewed code and worked cross-functionally to ship features spanning web and mobile platforms.

## Nursery management system

- Owned the system end to end (design, implementation and delivery), maintaining it mostly solo.
- Implemented dynamic educational templates based on Finnish educational standards, with custom components and API endpoints.
- Developed a real-time chat system for teacher-parent interactions.
- Upgraded the codebase from Rails 5 to Rails 6, redesigning and refactoring for maintainability and readability across the full-stack application.
- Established testing coverage across acceptance, integration and unit tests.
- Collaborated in an agile team, giving technical guidance on solution architecture.

## Stack

Ruby 2.3 and 2.7, Rails 2, 5 and 6, MySQL, PostgreSQL, Redis, Sidekiq, Devise, JavaScript, React.js, Grape, AWS, RSpec, Capybara.
